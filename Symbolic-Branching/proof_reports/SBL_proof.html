SB-L: Uses Hamming distance selector. NOT ideal for any parameters.

Reference: Theorem 3.4 (SB-L is NOT pairwise-ideal)

Reductions Applied

  • SB-L uses Hamming selector.
  • Symbolic parameters: L (lower bound), U (upper bound), P (precedence margin).
  • M = U - L + P (big-M coefficient).

    8. Methodology

    How This Proof Works

    1. Formulation Setup: The MIP formulation is expressed with symbolic parameters \(L, U, P\) so results hold for all valid parameter combinations.
    2. Constraint Analysis: Forbidden pairs (parallel constraints) are detected to prune the search space.
    3. Vertex Enumeration: A branch-and-bound tree explores all combinations of \(n\) tight constraints (where \(n\) = number of variables minus equality constraints).
    4. Symbolic Solution: For each potential vertex, the linear system is solved symbolically using exact arithmetic.
    5. Integrality Analysis: Binary variable values are analyzed to determine if they are:
      • Always integral: Value is 0 or 1 for all valid parameters
      • Conditional: Integral only when certain parameter conditions hold
      • Always fractional: Never integral for any valid parameters
    6. Idealness Determination: The formulation is ideal iff all feasible vertices have integral binary components.
